#Handloan Tracking Requirements
1. Add a new tab to VantagePoint App for tracking the Handloans. Give it an appropriate name.
2. As of now, a spreadsheet is used to track the handloans given out to friends and family. The tracking sheet has the following columns to track the handloans. 
"Borrower Name","Notes & Comments", "Loan Date","Closed Date",Loan Amount","Status","Interest Rate","Total Interest Months","Interest Balance Months","Interest / Month","Total Overall Interest","Interest Balance","Interest Payment 1","Date1","Interest Payment2","Date2","Interest Payment3","Date3","Interest Payment4","Date4"
3. Below are some typical use cases around it:
Loan can be given out to same borrower multiple times, modes, some times on same day and some times on different days and some times in a different year as well. As long as the loan is not repaid, it is usually tracked as Active. Once full loan is repaid, it is tracked as Repaid. Some times, interest is paid on-going basis, some times monthly basis, some times, quarterly or half yearly or random dates. There should be an ability to track the total interest payements recieved, dates, modes, comments, for each interest payment against a given loan. 
At times, interest is payment remains pending even when the Principal is totally repaid. There should be an ability to track such pending interest payements.
At times, partial payments are done and there should be a way to incorporate partial payments and then from that date, calculate only interest for pending principal amount. There should be a way to track the partial payments done as well.
There should be a way to view / filter, active vs repaid vs partially repaid loans. Total handloans and pending interst for selected view should be displayed as a tile. If no filter is selcted, then total handloan amount and pending interest should be shown in titles for all the amount. The pending interst for repaid principale should be shwon in a separate tile vs pending interest for active loans.
4. There should be a way to view / filter the loans with borrower name as well. There should be an ability to select multiple filters at once. There should be a way to sort by Borrower Name, Status, Loan Date, Load Amount field values.
5. There should be a way to export all the loan amounts into a csv sheet and or pdf as well.
